# Third-party asset credits

## Current default

- **Tyre** and **Tiger** ship as original procedural geometry created for Lucis.
  No third-party model license is required for the default experience.

## Recommended realistic replacements (CC0 / commercial-ok)

Place files in `public/models/`:

| File | Source | License |
|------|--------|--------|
| `tyre.glb` | [Innerscene 18" alloy + tyre](https://www.innerscene.com/tools/library/3d-parts/18-inch-alloy-wheel-with-tyre-225-40-r18-a5a47d63) or [Sketchfab CC0 Detailed Tire](https://sketchfab.com/3d-models/free-detailed-tire-public-domain-cc0-2844a0665550471fb2e8fbd1fd9e2e5e) | CC0 |
| `tiger.glb` | [Innerscene Tiger](https://www.innerscene.com/tools/library/3d-parts/tiger-3a01b408) | CC0 |

The scene automatically uses a GLB when present and falls back to the improved procedural models otherwise.

Always verify the license on the download page before commercial use.
